# NTE Wish Tracker

Запуск: `python main.py` (рядом с `main.py` лежат папки `assets/`, `icons/` и база `nte_wishes.db`).

Зависимости: `pip install PyQt6`; для OCR — `pip install pytesseract pillow opencv-python numpy` и установленный Tesseract.

## Tesseract OCR (для распознавания скриншотов)

Tesseract — отдельная программа, в репозиторий она **не** входит. Программа ищет её в таком порядке:

1. папка `Tesseract-OCR/` рядом с `main.py` (или с `.exe`, или рядом с базой данных) — «портативный» вариант;
2. `C:\Program Files\Tesseract-OCR\` (и `Program Files (x86)`) — обычная установка;
3. переменная `PATH`.

Установка: скачайте установщик для Windows со страницы https://github.com/UB-Mannheim/tesseract/wiki и при установке
отметьте язык **Russian** (нужен файл `tessdata/rus.traineddata`).

**Портативная сборка без установки.** Установите Tesseract на своём компьютере, скопируйте папку
`C:\Program Files\Tesseract-OCR` целиком (с подпапкой `tessdata`) рядом с `main.py` / `.exe`
и выложите архив в раздел **Releases** на GitHub, а не в код репозитория. Лицензия Tesseract — Apache 2.0.

История изменений прежнего однофайлового `main.py` — в `CHANGELOG.txt`.

## Структура

Слои идут сверху вниз; модуль импортирует только то, что расположено выше (циклических импортов нет).

| Модуль | Назначение |
|---|---|
| `compat.py` | Необязательные зависимости (QtMultimedia, requests, Pillow, pytesseract, OpenCV, NumPy). |
| `config.py` | Простые настройки и константы приложения (заголовок, формат дат, баннеры, музыка, профили, анимации). |
| `catalog.py` | Игровые справочники: баннеры, ранги, составы персонажей, дуги, наряды, виды предметов и лут. |
| `errors.py` | Исключения приложения. |
| `paths.py` | Работа с путями: папка программы, база данных, поиск ресурсов и музыки. |
| `icons.py` | Поиск и отрисовка иконок персонажей, дуг и предметов. |
| `labels.py` | Названия и текстовые описания предметов, круток и статистики. |
| `importing.py` | Нормализация записей и загрузка из JSON / CSV / логов. |
| `ocr/dates.py` | Русские даты и время на скриншотах (распознавание, разбор, нормализация). |
| `ocr/config.py` | Параметры и регулярные выражения OCR. |
| `ocr/preprocess.py` | Подготовка снимка к распознаванию (масштаб, бинаризация, Tesseract). |
| `ocr/layout.py` | Слова, строки и столбцы таблицы по результату Tesseract. |
| `ocr/enhance.py` | Улучшение отдельных фрагментов (названия, цветные плашки) для повторного OCR. |

## Заметки

* Главное окно (`mainwindow/window.py`) собрано из миксинов по вкладкам; логика методов не менялась.
* Папка данных базы запоминается через `paths.set_data_dir()` и читается через `paths.search_roots()`
  (раньше это была глобальная переменная `_DATA_DIR`, которую нельзя безопасно импортировать между модулями).
* `paths.app_dir()` по-прежнему указывает на папку с `main.py` (в сборке PyInstaller — на папку exe).
* Для PyInstaller: `pyinstaller --noconfirm --windowed main.py` (пакет `nte_tracker` подхватится автоматически).
